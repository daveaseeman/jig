## Built
M3 judges the branch since it left trunk, not the commit: one `--no-renames` diff of the index
against the merge base with trunk (and trunk's upstream, so a pulled trunk moves the base).
A line an earlier commit on the branch added covers later page-only commits; a commit that drops
the branch's only line, or deletes CHANGELOG.md, is refused. Paths are read with
`core.quotePath=false`, so non-ASCII page names count. RULES.md's M3 row, the stage skill's hint
and its comment in jig.py say the same. On trunk the base is HEAD: unchanged.
